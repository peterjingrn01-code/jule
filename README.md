# JULE™ Browser Alpha 0.4.1

## Product definition
JULE is a minimal browser interface: **Open Anything.**
It is not a search engine. Search remains separate through the JSL Discovery Engine.
JULE is a browser normalizer!

## Publish
Upload all files in this folder to the root of the GitHub repository, then deploy with GitHub Pages or Cloudflare Pages.

Required root files:
- `index.html`
- `manifest.webmanifest`
- `sw.js`
- `404.html`

## Open behavior
- `example.com` → opens `https://example.com`
- `https://example.com` → opens directly
- `localhost:8787` or local IP → opens with `http://`
- Search words are intentionally not sent to any search engine

## Ω 1–8 quick slots
- Press a numbered slot to open its saved address.
- Press and hold a numbered slot to save the address currently typed in the Open Bar.
- Ω clears the Open Bar and returns focus to it.
